# Stock Project Final

A data analysis school project focused on stock price analysis, visualization, and predictive modeling using real historical market data.

## Overview
This school assignment demonstrates an end-to-end data science workflow: collecting stock data, performing exploratory analysis, creating visualizations, and building models to predict price trends.

## What It Includes
- Fetching historical stock prices (Open, High, Low, Close, Volume)
- Data cleaning and exploratory data analysis (EDA)
- Visualizations (candlestick charts, moving averages, correlation heatmaps, volatility plots)
- Predictive modeling (machine learning and/or time-series forecasting)
- Analysis of trends, correlations, and volatility

## Project Structure
- `Final_Project.py` — Main script containing the full analysis and prediction workflow

## Technologies Used
Python • Pandas • NumPy • Matplotlib • Seaborn • Scikit-learn • yfinance
